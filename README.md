## v2.5.6 - 도서별 참조파일 관리
- 마케팅 기획 상세 화면에 참조 자료 영역 추가

- 실제 파일: Y:\출판사업본부\06. 출판 마케팅 운영 시스템\data\attachments\<제품코드>\ 저장
- Supabase `마케팅참조파일` 테이블에는 파일 메타데이터만 저장
- 파일 분류, 설명, 특정 마케팅 활동 연결 지원
- 등록 파일 열기 / 정보 수정 / 삭제 지원
- 삭제 시 Y드라이브 실제 파일과 Supabase 메타데이터 함께 제거

- 활동 목록과 시계열 모두 저장된 우선순위를 동일하게 반영
- 다른 날짜 또는 다른 분류로 드래그할 경우 변경을 막고 안내 메시지 표시
