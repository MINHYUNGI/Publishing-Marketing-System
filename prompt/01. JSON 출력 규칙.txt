JSON 출력 규칙

- 값을 확인할 수 없으면 빈 문자열 대신 null을 사용한다.
- 날짜는 YYYY-MM-DD 형식만 사용한다.
- 비용은 원 단위 정수로 기록한다.
- 활동분류는 '서점 마케팅', 'SNS·바이럴', '기타 추가 마케팅' 중 하나만 사용한다.
- 계획실행구분은 '계획', '실행', '추가' 중 하나만 사용한다.
- 각 활동에는 짧은 원문 근거와 0~1 사이의 확신도를 기록한다.
- 확인이 필요한 경우 needs_review=true와 review_reason을 기록한다.
- 한 문단이나 셀에 여러 활동이 있으면 가능한 범위에서 개별 활동으로 분리한다.
